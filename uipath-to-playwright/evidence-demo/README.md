# Evidence Demo — LoginFlow (UiPath → Playwright)

> ⚠️ **This is a small demo fixture, NOT the real `UiPath_POC_TestAutomationProject`.** It exists only to prove
> the mapper produces real, passing Playwright execution (this project has only 1 tiny test against a public
> site). For the complete migration of the real project (1 test case + 8 reusable components, 102 activities,
> 100% mapped) see [`../output/uipath-poc-playwright-project/MIGRATION-EVIDENCE.html`](../output/uipath-poc-playwright-project/MIGRATION-EVIDENCE.html)
> (Python converter) or [`../../uipath-playwright-dm/MIGRATION-EVIDENCE.html`](../../uipath-playwright-dm/MIGRATION-EVIDENCE.html) (agent flow).

A real, executed proof that the `uipath-to-playwright` mapper produces working Playwright tests, with
before/after execution screenshot evidence.

## What actually ran here

1. `input/LoginFlow.xaml` (fixture, classic UiPath web activities) was converted with
   `python scripts/convert.py input/LoginFlow.xaml --output evidence-demo/tests/LoginFlow.spec.ts --screenshots evidence/after`.
2. `npx playwright test` executed the generated spec for real against the live `https://www.saucedemo.com`
   target — **1 passed**. Screenshots were captured automatically after every UI action into
   `evidence/after/loginflow/`.
3. A reference baseline was captured against the same site, same step order, into `evidence/before/loginflow/`
   (see [DEMO-EVIDENCE.md](DEMO-EVIDENCE.md) for the exact caveat: this baseline was captured
   without UiPath Studio/Robot, which is not installed in this environment).
4. `python ../scripts/build_evidence_report.py` paired the two screenshot sets and computed a Pillow
   pixel-similarity score per step, producing [DEMO-EVIDENCE.md](DEMO-EVIDENCE.md).

## Reproduce

```powershell
npm install
npx playwright install chromium
npx playwright test
```

## Structure

```
evidence-demo/
  package.json / playwright.config.ts
  tests/LoginFlow.spec.ts       ← generated by convert.py --screenshots
  evidence/before/loginflow/    ← reference baseline (see caveat above)
  evidence/after/loginflow/     ← real Playwright execution screenshots
  DEMO-EVIDENCE.md              ← generated comparison report (renamed from MIGRATION-EVIDENCE.md so it can
                                   never be mistaken for the real project's report)
```
