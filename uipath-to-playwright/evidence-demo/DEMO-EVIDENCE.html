Full Before/After Traceability — Every UiPath Object → Playwright Method (execution order)

One collapsible block per migrated source file, listing every activity in the exact order it executes (not just an aggregated count) — the complete before/after technical evidence: what test case, what UiPath object, and what Playwright method it became.

About the "UiPath Selector" column: UiPath does use locators — it calls them "Selectors" (an XML attribute string produced by UiPath's UI Explorer, e.g. <html tag='INPUT' automationid='user-name' />). This column shows the real, resolved selector read from the source .xaml for that exact activity, and the Playwright Conversion column shows the real, resolved generated code for that same occurrence (not a generic template). A "-" means that activity type has no locator in UiPath either (e.g. a log message, variable assignment, or loop has nothing to select on).
